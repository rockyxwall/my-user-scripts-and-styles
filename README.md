## how to install

### user-styles

you'll need an extension like **[Stylus](https://add0n.com/stylus.html)**. it's the best one for this.

1. get [Stylus](https://add0n.com/stylus.html).
2. click the install link for whichever style you want below.
3. hit the install button on the page that opens.
